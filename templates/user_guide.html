1. Getting Started

  • Pick a league from the dropdown in the top navbar. Supported competitions include IPL, BBL, BPL, CPL, ILT20, LPL, MLC, NPL, PSL, SA20, T20 Blast, The Hundred (M/W), WBBL and WPL — whichever data files are available.
  • The dashboard reloads automatically and remembers your selection across pages.
  • On phones, tap the navbar toggler to access Home, Batting, Bowling, Head-to-Head, Venue Stats, Phase Analysis and the User Guide. Wide tables scroll horizontally and the player/bowler name column stays pinned.

2. Main Features

  • Home – Player Database & Quick Search: Type any player name (full name, surname or alias like "Virat Kohli" → "V Kohli"). Filter by one or more seasons and by venue, then get a full stats card for that player.
  • Batting Leaderboard: Full league leaderboard with Matches, Balls, Runs, Avg, SR, 100s, 50s, HS, RPI, Dot%, BPD and BPB. Filter by minimum innings, innings (All / 1st / 2nd) and any subset of seasons.
  • Bowling Leaderboard: Full leaderboard with Matches, Balls, Runs, Wickets, Avg, Eco, SR, Best, 5W+, Dot% and BPB. Same filter set as Batting.
  • Head-to-Head: Single matchup or bulk matchup grids between any bowler(s) and batsman(s), with optional innings and venue scoping.
  • Venue Stats: Per-venue averages, win/loss splits, bat-first vs chase win %, biggest totals, lowest totals, highest successful chase and a per-team breakdown. Multi-season filter supported.
  • Phase Analysis: Powerplay/middle/death breakdowns (PP1 overs 1–6, PP2 7–10, PP3 11–15, PP4 16–20) including overall phase averages, win-vs-loss split, batting-1st-vs-2nd split with innings counts, per-team breakdown and recent matches.

3. Player Stats Explained

Batsman Quick Stats (Home card) & Batting Leaderboard:
  • Matches / Innings: Number of matches the player batted in
  • Balls: Total balls faced
  • Runs: Total runs scored
  • Average (Avg): Runs per innings (Runs / Innings) — matches the Home card "Average"
  • Strike Rate (SR): (Runs / Balls) × 100
  • 100s / 50s: Centuries / Fifties scored
  • Highest Score (HS): Top runs in a single match
  • RPI (All / 1st / 2nd): Runs per innings split — overall, batting 1st only, batting 2nd only (shown on the Home card)
  • Dot %: % of balls faced scoring zero
  • BPD (Balls Per Dismissal): Balls faced / Times out — survival metric (higher = better)
  • BPB (Balls Per Boundary): Balls faced / (Fours + Sixes) — boundary frequency (lower = better)
Bowler Quick Stats (Home card) & Bowling Leaderboard:
  • Matches / Innings: Matches bowled in
  • Balls: Total legal deliveries
  • Runs: Runs conceded
  • Wickets: Total wickets (excluding run-outs and retirements)
  • Avg: Runs conceded per wicket (lower = better)
  • Eco: Economy rate, runs per over (lower = better)
  • SR: Balls bowled / Wickets (lower = better)
  • Wkts (1st / 2nd): Innings-wise wicket split (Home card only)
  • Best: Most wickets in a single match
  • 5W+: Times the bowler took 5 or more wickets in a match
  • Dot %: % of dot balls
  • BPB: Balls bowled / (Fours + Sixes conceded) — boundary protection (higher = better)

4. Head-to-Head Matchup Analysis

What is Head-to-Head? Compare any bowler and batsman's real historical encounters ball-by-ball.
How to Use: Pick a single bowler/batsman, or load multiple of each for a matchup grid. Use the global innings filter (All / 1st / 2nd) and optionally restrict to one venue. Reset all inputs with the orange Reset button.

  • Balls: Balls faced in this matchup
  • Runs: Runs scored off this bowler
  • Wickets: Number of dismissals
  • Dot Balls: Balls with zero runs
  • Strike Rate: Batting SR in the matchup
  • Economy: Bowler's runs per over in matchup
  • Dot %: % of dot balls
  • Matches: Matches in which this matchup occurred
  • Status: "Found" if balls exist between the pair, otherwise "No Match"
Venue Head-to-Head: Choose a venue (canonical names are auto-normalised across spelling variants) and the matchup stats restrict to that ground only — useful for spotting venue-specific matchup edges.

5. Venue Stats Page

  • Multi-season filter: Pick any subset of seasons via the dropdown checkboxes.
  • Averages: 1st-innings average, 2nd-innings average, completed-match count.
  • Win split: Bat-First Win % vs Chase Win % (over matches where both innings completed).
  • High / Low scores: Matches with any innings 180+ ("High Scores") or under 150 ("Low Scores").
  • Record cards: Highest team total, lowest team total (≥50), highest successful chase at the venue.
  • Per-team breakdown: Matches, total runs, average per innings, HS, LS and wins for each team at the venue.

6. Phase Analysis Page

  • Phases: PP1 (overs 1–6), PP2 (7–10), PP3 (11–15), PP4 (16–20). Colour-coded red/yellow/orange/green throughout.
  • Overall phase averages: Avg runs and wickets per phase across all innings in the filter.
  • Win-vs-Loss table (when a team is selected): Average phase runs in their wins vs losses.
  • Batting 1st vs 2nd table: Phase averages split by innings, with innings counts so small samples are visible.
  • Per-team breakdown (when no team is selected): Average phase runs for every team.
  • Recent matches: Phase-by-phase scoreline for the latest matches in scope.
  • Phase Specialists: Top 10 batters (by Strike Rate) and bowlers (by Economy) for each phase — Powerplay, Middle 1, Middle 2, Death. Min 15 balls (batters) / 30 balls (bowlers) in the phase to qualify, so you only see real specialists, not lucky cameos.

6a. Team vs Team Page

  • Pick Team A and Team B (optionally a venue, innings or season filter).
  • Overall H2H: Matches, wins for each side, win %, no-results and average score per team.
  • Venue H2H: Per-venue matches and wins between the two teams.
  • Last 5 Matches: Most recent meetings with both scorelines, winner and margin.
  • Top Run Scorers / Top Wicket Takers: Best individual performers across all fixtures between the two teams.

6b. Win Patterns Page

  • Pick a team (optionally a venue or seasons).
  • Highlight cards: Win % when scoring 180+ batting first, 200+ batting first, and chasing 180+.
  • Score Buckets — Batting 1st: Win rate by total posted (<120, 120-149, 150-179, 180-199, 200+).
  • Chase Targets: Win rate by target faced (same buckets) — useful for fantasy and toss-decision insight.

7. Filters, Sorting, and Navigation

  • Minimum Innings: Hide players below the threshold on Batting/Bowling pages.
  • Innings Filter: All / 1st / 2nd — works on Batting, Bowling, Head-to-Head.
  • Season Filter (multi-select): Available on Home, Batting, Bowling, Venue Stats and Phase Analysis. Tick any combination; the button shows "All Seasons" or a comma-separated list of the selected years.
  • Venue Filter: On Home and Head-to-Head; canonical venue names map across spelling variants.
  • Clear All: Yellow Clear button on filter dropdowns resets selections.
  • League Selector: Top-right navbar — switch leagues without losing the current page.

7a. App Experience — Themes, Install, Compare & Smart Tables

Dark / Light Theme

  • Tap the 🌙 / ☀️ button in the top-right navbar to switch between light and dark.
  • Your choice is saved and applied automatically on every visit — no flicker on load.
  • First-time visitors automatically get the theme that matches their device setting.

Install as an App (PWA)

  • Android / Chrome / Edge: tap the Install button that appears in the navbar, or use the browser menu → "Install app" / "Add to Home screen".
  • iPhone / Safari: tap the Share icon → Add to Home Screen.
  • Once installed it opens full-screen with its own icon, just like a native app.
  • Offline: pages and stats you've already opened keep working without internet. Live data (new searches) still needs a connection.

Compare Two Players

  • On the Home page, open the "Compare Two Players" panel.
  • Type two player names (autocomplete helps), choose Batsman or Bowler, and tap Compare.
  • You get a side-by-side table with the better value highlighted (it correctly treats lower-is-better stats like bowling Average, Economy and Strike Rate), plus a bar chart of the key metrics.
  • Comparison uses the league currently selected in the navbar.

Smart Tables

  • Sort: tap any column header on the big leaderboards to sort ascending/descending.
  • Quick filter: type in the box above large tables to instantly narrow rows.
  • Export CSV: download the visible rows for use in Excel/Sheets.
  • Tooltips: hover (or tap) the abbreviated column headers to see what each stat means.
  • Colour badges: strong batting/bowling values are tinted green, weak ones red, for quick scanning.
  • Filter chips: your active filters appear as removable tags — tap the ✕ to drop one.
  • Sticky headers: on phones, column names stay pinned while you scroll long tables.

Mobile Navigation & Speed

  • A bottom navigation bar gives one-tap access to Home, Batting, Bowling, Head-to-Head and Venue. The current page is highlighted.
  • After you submit any filter or search, the page auto-scrolls to the results so you never miss them.
  • Search is debounced (waits until you pause typing) and scrolling is optimised to stay smooth on phones.

9. Tips & Best Practices

  • Use multi-season filters to compare a player's form across specific years rather than career totals.
  • On Venue Stats, compare Bat-First vs Chase Win % to gauge whether tosses matter at a ground.
  • On Phase Analysis, the Win-vs-Loss table reveals where a team typically gains or loses matches (e.g. death overs).
  • BPB highlights power hitters (low value) and boundary-conceding bowlers (low value = bad).
  • "Head-to-Head" uncovers hidden edges — e.g. a bowler who consistently dismisses a big-name batsman.

10. FAQ & Troubleshooting

  • Empty table after picking 1st/2nd Innings: Lower the Minimum Innings — only players with that many innings in the chosen innings are shown.
  • Player not found: Try a surname or partial name; aliases like full names usually resolve.
  • Season list looks short: Some leagues only have a few completed seasons in the dataset.
  • Stats look thin: Some advanced stats need enough balls/innings to be meaningful — raise the threshold.
